# 데모 자산 선정

## 선정 결과

웹 데모는 공개 매매사례로 소개된 **서울특별시 강남구 논현동 103-5** 건물을 참고 자산으로 사용한다.

주소와 공개된 건물 규모·준공연도·거래가격은 실제 사례를 참고한다. 임대차·대출·리모델링·매각 조건은 제품 흐름을 보여주기 위한 가정값이며 실제 건물의 현재 운영정보를 의미하지 않는다.

## 선정 이유

- 30억~150억 원이라는 초기 목표 가격대에 포함된다.
- 1990년 준공 건물로 임대 개선·리모델링·신축을 함께 검토할 수 있다.
- 대지와 연면적이 중소형 빌딩 투자자가 이해하기 쉬운 규모다.
- 인근에 다양한 가격대와 준공연도의 비교거래 사례가 있다.
- 단순 가격 조회보다 PLOT OS의 시나리오 분석 가치를 보여주기 적합하다.

## 표시 원칙

- 모든 화면에 `DEMO DATA`와 기준일을 표시한다.
- 주소는 공개 거래사례의 소재지를 표시하되 소유자와 임차인 정보는 사용하지 않는다.
- 공개 확인값과 제품 가정값을 구분한다.
- 감정평가, 법률판단, 투자권유 결과로 오인될 표현을 사용하지 않는다.
- 향후 실제 고객 사례를 사용할 때는 별도 동의와 익명화 절차를 적용한다.
