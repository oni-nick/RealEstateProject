## 진행이 막힐 때

- 후보가 없으면 검색어를 지우고 기본 프리셋을 다시 선택합니다. 본 건물은 IRR 미달 사례이므로 `가상 송파구 003` 검색 후 **조건 외도 보기**를 켜거나 위의 상세 경로로 바로 이동합니다.
- `산출 불가`는 0%가 아닙니다. 특히 공사 시나리오는 현금흐름 부호가 여러 번 바뀌어 단일 IRR을 확정하지 못할 수 있습니다. NOI·비용·근거를 중심으로 설명합니다.
