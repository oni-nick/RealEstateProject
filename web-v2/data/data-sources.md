# PLOT OS v2 · 데이터 출처와 한계 안내

예시 데이터 · 실제 매물 아님. 모든 수치는 검증 전 데모 가정입니다.

이 노트는 `docs/data-sources.md`의 핵심 주의를 배포 폴더 안에서 열 수 있도록 옮긴 요약입니다.
원본 행과 단위·범위·후보 기관·UNKNOWN은 [market_refs.json](./market_refs.json)에 있습니다.

- 신뢰도 low는 근거 미검증을 뜻하며 통계적 신뢰도나 수익 보장 확률이 아닙니다. 파생 수치도 입력의 미검증 상태를 상속합니다.
- 시장 참고 범위는 모델의 일반 지식으로 설정한 넓은 2024–2026 가정입니다. 2026년 11월 관측 시세가 아닙니다. 시장 관측일은 UNKNOWN입니다.
- 국토교통부·한국부동산원·알스퀘어·JLL·CBRE 등 기관명은 나중에 대조할 후보입니다. 보고서·API·대출조건서·고객 자료를 열람하지 않았습니다. URL·발행일·조회일은 UNKNOWN입니다.
- 건물 요약·호실별 임대차·운영비·비교 거래는 모두 합성 예시입니다. 실제 계약·거래·소유자 증빙이 아닙니다. 수정한 가정은 원래 참고 행에서 관측한 값이 아닙니다.
- 금액 저장 단위는 원(KRW), 비율은 소수(0.05 = 5%)입니다. 1평 = 400/121 m²입니다. 패널 원시 값은 화면의 억·만원 단위와 다를 수 있습니다.
- 계약 월세에는 기존 공실이 반영됩니다. 잠재 월세와 구별하며 공실을 중복 차감하지 않습니다. 면적 공실률과 임대료 손실률은 다릅니다.
- 보증금은 반환할 부채입니다. 초기 자금 필요액을 줄이지만 NOI 수입에 포함하지 않으며 매각 때 정산합니다.
- 취득세 예산 4.6%와 중개·금융 비용은 검증 전 예시입니다. 실제 세금·VAT·대출 심사·실제 운영비·공사 및 인허가 가능성은 UNKNOWN입니다. 감정평가·투자·대출·세무 자문에 사용할 수 없습니다.
