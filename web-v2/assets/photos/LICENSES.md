# Generated example imagery

All 32 facade SVGs are original procedural architectural illustrations generated by `tools/gen-photos.mjs` using Node built-ins. No downloaded photographs, third-party assets, real brands or identifiable building references are used.

- Rebuild from repository root: `node tools/gen-photos.mjs`. Stable inputs produce byte-identical SVG, manifest and catalog files. No network or packages required.
